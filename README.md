## My process
I used CSS Flexbox to display all the elements in a column, then I adjusted the neccessary sizing and applied border-radius on the container selector and the svg image. The title selector was given a hover behaviour and the overall layout was arranged to be responsive to different screen sizes from 320px to 1440px.
